# Luma Browser Lab

Antes de planear cambios, leer `docs/SEMILLA.md`. Usar su mapa para consultar solo los archivos necesarios. Revisar cambios existentes antes de editar; la carpeta aún puede no tener Git.

Mantener actualizada la semilla al cambiar comportamiento, arquitectura, pruebas, decisiones o pendientes. No guardar secretos. Diferenciar resultados controlados de cobertura general de Internet.

No modificar firmware, arranque, particiones ni DNS dentro de las fases actuales. No ejecutar interceptores o pruebas que naveguen la TV simultáneamente. Al terminar una prueba, restaurar la sesión del usuario y el buscador elegido. Comprobar IP y conexión actuales; no confiar en puertos guardados como estado vivo.
